TgFetch 1.0

Файлы из Telegram по просьбе словами

✳Установить через Claude❯_через CodexСкачать TgFetch-1.0.zip12 КБ · 2 октября 2026

Консольная утилита для Claude Code и Codex: находит чат, топик и человека и скачивает присланные файлы в папку проекта. Работает от твоего аккаунта и только читает. Отправка — отдельной командой и только после твоего «да».

Нестрогий поиск

«Маша» найдёт «Мария …», «montazh» — «Монтаж»: регистр, ё/е, кириллица и латиница.

Сначала просмотр

Агент показывает, что будет скачано, и только потом качает.

Сразу в RefTray

С флагом --tray скачанное появляется в панели — бери мышкой.

Вход только у тебя

Логин хранится в ~/.config/telegram и никуда не уходит. Вход ты делаешь сам.

Установка

Запрос агенту (Claude Code / Codex)
Поставь мне TgFetch со студийного хаба: прочитай каталог командой `curl -s https://mthought13.github.io/studio-hub/agent.md`, установи TgFetch командой оттуда и подключи его по инструкции для агента (AGENT.md).
Кнопки «Установить через Claude / Codex» вставляют его сами. Если приложение агента не открылось — скопируй и вставь вручную.
Или в Терминале
curl -fsSL https://mthought13.github.io/studio-hub/install.sh | bash -s -- tgfetch
Ставит в «Программы», без предупреждения Gatekeeper. Обновление — та же команда.

Инструкция

TgFetch — файлы из Telegram для агента

Твой Claude Code или Codex скачивает файлы из чатов и топиков Telegram по просьбе словами: «скачай последние два видео от Маши из топика «Монтаж» в папку проекта». Работает от имени твоего аккаунта и только читает. Отправить файл агент может лишь после твоего «да».

Это консольная утилита, окна у неё нет. Нужен macOS и python3 (если его нет, macOS предложит установить «инструменты разработчика» — соглашайся).

Установка

  1. Распакуй архив так, чтобы получилась папка ~/TgFetch (в домашней папке).
  2. В Терминале: 
    ~/TgFetch/setup.sh
  3. Войди в Telegram (один раз, всё вводишь сам): 
    ~/TgFetch/login.sh

    Понадобятся api_id и api_hash: зайди на my.telegram.org → API development tools → создай приложение (название любое). Потом телефон, код из Telegram и облачный пароль, если он есть. Вход хранится только у тебя: ~/.config/telegram/. В Telegram появится устройство «Studio Fetch (Mac)». Отключить — Telegram → Настройки → Устройства.

Подключить агента

Скажи Claude Code или Codex:

Прочитай ~/TgFetch/AGENT.md и подключи TgFetch: добавь блок из раздела «Подключение» в мои глобальные инструкции.

Удалить

Удали папку ~/TgFetch и ~/.config/telegram, а в Telegram → Настройки → Устройства заверши сеанс «Studio Fetch (Mac)».

Инструкция для агента

AGENT.md — открыть как текст

TgFetch — инструкция для агента (Claude Code / Codex)

TgFetch скачивает файлы из чатов и топиков Telegram от имени аккаунта человека: «скачай последние два видео от Маши из топика «Монтаж» в папку проекта». Работает только на чтение. Отправка (tgsend) — отдельная команда и только после подтверждения человека. Прочитай файл целиком, потом выполни раздел «Подключение».

Где что лежит

ЧтоПуть
Команды~/TgFetch/tgfetch, ~/TgFetch/tgsend, ~/TgFetch/login.sh
Окружение Python~/TgFetch/.venv (ставит ~/TgFetch/setup.sh)

Псевдонимы людей~/.config/telegram/people.json → {"маша": 123456789} (id из tgfetch people)
Журнал скачиваний~/TgFetch/downloads.log

Команды

tgfetch chats [запрос]                                   # найти чат
tgfetch topics CHAT                                      # топики группы
tgfetch people CHAT [--topic T]                          # кто присылал файлы
tgfetch list CHAT [--topic T] [--from ИМЯ] [--last N]    # что будет скачано (ничего не качает)
tgfetch get  CHAT [--topic T] [--from ИМЯ] [--last N] --to ПАПКА [--tray]
  • Всегда сначала list, потом get с теми же параметрами.
  • Имена чатов, топиков и людей ищутся нестрого: регистр, ё/е, кириллица/латиница, начало слова («Маша» → «Мария …»).
  • --tray сразу показывает скачанное в RefTray (если он стоит).
  • Коды выхода: 0 — ок, 2 — ничего не найдено, 3 — несколько вариантов (кандидаты напечатаны, уточни у человека), 4 — не выполнен вход.
  • Картинки, отправленные «как фото», Telegram сжимает. Скажи об этом человеку: оригинал только если присылать «как файл».

Отправка — только с подтверждением

tgsend CHAT [--topic T] --file ПУТЬ --caption "текст"          # пробный прогон: показывает, что уйдёт
tgsend CHAT [--topic T] --file ПУТЬ --caption "текст" --yes    # реально отправить

--yes добавляй только после того, как человек в чате подтвердил точный чат, топик, файл и подпись.

Подключение

  1. Если нет ~/TgFetch/.venv — запусти ~/TgFetch/setup.sh (нужен python3; если его нет, попроси человека выполнить xcode-select --install).
  2. Вход делает сам человек в своём Терминале: ~/TgFetch/login.sh. Ему понадобятся api_id и api_hash со страницы my.telegram.org → API development tools, телефон, код из Telegram и облачный пароль. Не проси его прислать это в чат и не вводи за него.
  3. Проверь: ~/TgFetch/tgfetch chats — должен вывести чаты (код 4 = вход не выполнен).
  4. Добавь в глобальные инструкции человека (~/.claude/CLAUDE.md / ~/.codex/AGENTS.md): 
    ## TgFetch — файлы из Telegram
- `~/TgFetch/tgfetch chats|topics|people|list|get …` (только чтение). Всегда `list`, потом `get`. Подробности: `~/TgFetch/AGENT.md`.
- Отправка `~/TgFetch/tgsend … --yes` — только после моего подтверждения точного чата, топика, файла и подписи.
- Код выхода 4 = сессия истекла: я сам запускаю `~/TgFetch/login.sh`.
