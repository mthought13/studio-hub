# TgFetch — файлы из Telegram для агента

Твой Claude Code или Codex скачивает файлы из чатов и топиков Telegram по просьбе словами:
«скачай последние два видео от Маши из топика «Монтаж» в папку проекта». Работает от имени твоего аккаунта и только читает. Отправить файл агент может лишь после твоего «да».

Это консольная утилита, окна у неё нет. Нужен macOS и `python3` (если его нет, macOS предложит установить «инструменты разработчика» — соглашайся).

## Установка
1. Распакуй архив так, чтобы получилась папка `~/TgFetch` (в домашней папке).
2. В Терминале:
   ```bash
   ~/TgFetch/setup.sh
   ```
3. Войди в Telegram (один раз, всё вводишь сам):
   ```bash
   ~/TgFetch/login.sh
   ```
   Понадобятся `api_id` и `api_hash`: зайди на **my.telegram.org** → API development tools → создай приложение (название любое). Потом телефон, код из Telegram и облачный пароль, если он есть.
   Вход хранится только у тебя: `~/.config/telegram/`. В Telegram появится устройство «Studio Fetch (Mac)». Отключить — Telegram → Настройки → Устройства.

## Подключить агента
Скажи Claude Code или Codex:

> Прочитай ~/TgFetch/AGENT.md и подключи TgFetch: добавь блок из раздела «Подключение» в мои глобальные инструкции.

## Удалить
Удали папку `~/TgFetch` и `~/.config/telegram`, а в Telegram → Настройки → Устройства заверши сеанс «Studio Fetch (Mac)».
