# TgFetch — инструкция для агента (Claude Code / Codex)

**TgFetch** скачивает файлы из чатов и топиков Telegram от имени аккаунта человека: «скачай последние два видео от Маши из топика «Монтаж» в папку проекта». Работает только на чтение. Отправка (`tgsend`) — отдельная команда и только после подтверждения человека. Прочитай файл целиком, потом выполни раздел «Подключение».

## Где что лежит
| Что | Путь |
|---|---|
| Команды | `~/TgFetch/tgfetch`, `~/TgFetch/tgsend`, `~/TgFetch/login.sh` |
| Окружение Python | `~/TgFetch/.venv` (ставит `~/TgFetch/setup.sh`) |
| Вход в Telegram | `~/.config/telegram/` — `api.json`, `tgfetch.session` (папка 700, файлы 600). **Никогда не читай, не выводи и не копируй эти файлы.** |
| Псевдонимы людей | `~/.config/telegram/people.json` → `{"маша": 123456789}` (id из `tgfetch people`) |
| Журнал скачиваний | `~/TgFetch/downloads.log` |

## Команды
```bash
tgfetch chats [запрос]                                   # найти чат
tgfetch topics CHAT                                      # топики группы
tgfetch people CHAT [--topic T]                          # кто присылал файлы
tgfetch list CHAT [--topic T] [--from ИМЯ] [--last N]    # что будет скачано (ничего не качает)
tgfetch get  CHAT [--topic T] [--from ИМЯ] [--last N] --to ПАПКА [--tray]
```
- Всегда сначала `list`, потом `get` с теми же параметрами.
- Имена чатов, топиков и людей ищутся нестрого: регистр, ё/е, кириллица/латиница, начало слова («Маша» → «Мария …»).
- `--tray` сразу показывает скачанное в RefTray (если он стоит).
- Коды выхода: 0 — ок, 2 — ничего не найдено, 3 — несколько вариантов (кандидаты напечатаны, уточни у человека), **4 — не выполнен вход**.
- Картинки, отправленные «как фото», Telegram сжимает. Скажи об этом человеку: оригинал только если присылать «как файл».

## Отправка — только с подтверждением
```bash
tgsend CHAT [--topic T] --file ПУТЬ --caption "текст"          # пробный прогон: показывает, что уйдёт
tgsend CHAT [--topic T] --file ПУТЬ --caption "текст" --yes    # реально отправить
```
`--yes` добавляй только после того, как человек в чате подтвердил точный чат, топик, файл и подпись.

## Подключение
1. Если нет `~/TgFetch/.venv` — запусти `~/TgFetch/setup.sh` (нужен `python3`; если его нет, попроси человека выполнить `xcode-select --install`).
2. **Вход делает сам человек** в своём Терминале: `~/TgFetch/login.sh`. Ему понадобятся `api_id` и `api_hash` со страницы my.telegram.org → API development tools, телефон, код из Telegram и облачный пароль. Не проси его прислать это в чат и не вводи за него.
3. Проверь: `~/TgFetch/tgfetch chats` — должен вывести чаты (код 4 = вход не выполнен).
4. Добавь в глобальные инструкции человека (`~/.claude/CLAUDE.md` / `~/.codex/AGENTS.md`):
   ```markdown
   ## TgFetch — файлы из Telegram
   - `~/TgFetch/tgfetch chats|topics|people|list|get …` (только чтение). Всегда `list`, потом `get`. Подробности: `~/TgFetch/AGENT.md`.
   - Отправка `~/TgFetch/tgsend … --yes` — только после моего подтверждения точного чата, топика, файла и подписи.
   - Код выхода 4 = сессия истекла: я сам запускаю `~/TgFetch/login.sh`.
   ```
