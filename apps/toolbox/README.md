# Toolbox — системный виджет в строке меню

Значок — сетка 2×2 в строке меню. Внутри вкладки:
- **Звук** — каждой программе своё устройство вывода, громкость и mute. Например, музыка в наушники, Resolve в мониторы, созвон в AirPods.
- **Окна** — разложить окна по шаблону одним нажатием: ⌃⌥1…⌃⌥8 (2 рядом, 2/3 + 1/3, 3 колонки, 4 сеткой…). Повтор того же шаблона меняет окна местами.
- **Цвет** — баланс белого, яркость, контраст и цветовые профили экранов.

Нужен macOS 14.2 или новее, подходит и для Apple Silicon, и для Intel. Весит ~2 МБ, в простое почти не тратит процессор.

## Установка
1. Открой `Toolbox.dmg` и перетащи **Toolbox** в папку **Applications**.
2. Запусти Toolbox из «Программ». Приложение не проходило проверку Apple (нотаризацию), поэтому в первый раз macOS его не откроет:
   - **Системные настройки → Конфиденциальность и безопасность** → внизу «Toolbox заблокировано» → **«Всё равно открыть»**;
   - или одной командой в Терминале:
     ```bash
     xattr -dr com.apple.quarantine /Applications/Toolbox.app
     ```
3. Разрешения (macOS спросит сама, когда понадобится):
   - для **Звука** — «Запись экрана и системного звука» → раздел **«Только системный звук»** → включи Toolbox;
   - для **Окон** — «Универсальный доступ» → включи Toolbox.
4. Автозапуск: шестерёнка в панели → «Запускать при входе».

## Обновления
Если ставил с хаба, новые версии приходят сами. Когда выйдет обновление, на значке появится красная точка,
а в шестерёнке — «Доступно обновление». Нажми: Toolbox закроется на секунду и откроется уже новым, настройки сохранятся.

## Подключить агента
Скажи своему Claude Code или Codex:

> Прочитай инструкцию для агента из DMG Toolbox (или ~/Toolbox/AGENT.md) и подключи Toolbox: добавь блок из раздела «Подключение» в мои глобальные инструкции.

После этого можно просить словами: «пусти Telegram в наушники», «разложи окна на три колонки», «сделай экран потеплее».

## Удалить
Выйди из Toolbox (шестерёнка → «Выйти из Toolbox»), удали `/Applications/Toolbox.app`, папку `~/Library/Application Support/Toolbox` и файл `~/Library/LaunchAgents/local.toolbox.plist`.
