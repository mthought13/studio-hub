Toolbox 1.2

Звук по приложениям, раскладка окон, цвет экранов

✳Установить через Claude❯_через CodexСкачать Toolbox-1.2.dmg1.7 МБ · 2 октября 2026

Значок-сетка в строке меню с системными инструментами на вкладках. Каждой программе — своё устройство вывода и громкость, окна раскладываются по шаблонам одной клавишей, экраны подстраиваются по цвету. Всё это можно попросить у агента словами.

Звук

Музыка в наушники, Resolve в мониторы, созвон в AirPods — у каждой программы своё устройство, громкость, mute и пара каналов.

Окна

⌃⌥1…8: 2 рядом, 2/3 + 1/3, 3 колонки, 4 и 6 сеткой. Повтор шаблона меняет окна местами.

Цвет

Баланс белого, яркость, контраст, гамма, подсветка дисплеев Apple и цветовые профили.

Команды для агента

toolbox audio | windows | color — агент выполняет просьбы словами: «пусти Telegram в наушники», «разложи окна на три колонки».

Установка

Запрос агенту (Claude Code / Codex)
Поставь мне Toolbox со студийного хаба: прочитай каталог командой `curl -s https://mthought13.github.io/studio-hub/agent.md`, установи Toolbox командой оттуда и подключи его по инструкции для агента (AGENT.md).
Кнопки «Установить через Claude / Codex» вставляют его сами. Если приложение агента не открылось — скопируй и вставь вручную.
Или в Терминале
curl -fsSL https://mthought13.github.io/studio-hub/install.sh | bash -s -- toolbox
Ставит в «Программы», без предупреждения Gatekeeper. Обновление — та же команда.

Разрешения и требования

  • Запись системного звука («Только системный звук») — для вкладки «Звук»
  • Универсальный доступ — для вкладки «Окна»

Windows

Штатные аналоги: Параметры → Система → Звук → «Громкость приложений» (своё устройство каждой программе) и PowerToys FancyZones (раскладка окон).

Инструкция

Toolbox — системный виджет в строке меню

Значок — сетка 2×2 в строке меню. Внутри вкладки:

  • Звук — каждой программе своё устройство вывода, громкость и mute. Например, музыка в наушники, Resolve в мониторы, созвон в AirPods.
  • Окна — разложить окна по шаблону одним нажатием: ⌃⌥1…⌃⌥8 (2 рядом, 2/3 + 1/3, 3 колонки, 4 сеткой…). Повтор того же шаблона меняет окна местами.
  • Цвет — баланс белого, яркость, контраст и цветовые профили экранов.

Нужен macOS 14.2 или новее, подходит и для Apple Silicon, и для Intel. Весит ~2 МБ, в простое почти не тратит процессор.

Установка

  1. Открой Toolbox.dmg и перетащи Toolbox в папку Applications.
  2. Запусти Toolbox из «Программ». Приложение не проходило проверку Apple (нотаризацию), поэтому в первый раз macOS его не откроет:
    • Системные настройки → Конфиденциальность и безопасность → внизу «Toolbox заблокировано» → «Всё равно открыть»;
    • или одной командой в Терминале: 
      xattr -dr com.apple.quarantine /Applications/Toolbox.app
  3. Разрешения (macOS спросит сама, когда понадобится):
    • для Звука — «Запись экрана и системного звука» → раздел «Только системный звук» → включи Toolbox;
    • для Окон — «Универсальный доступ» → включи Toolbox.
  4. Автозапуск: шестерёнка в панели → «Запускать при входе».

Обновления

Если ставил с хаба, новые версии приходят сами. Когда выйдет обновление, на значке появится красная точка, а в шестерёнке — «Доступно обновление». Нажми: Toolbox закроется на секунду и откроется уже новым, настройки сохранятся.

Подключить агента

Скажи своему Claude Code или Codex:

Прочитай инструкцию для агента из DMG Toolbox (или ~/Toolbox/AGENT.md) и подключи Toolbox: добавь блок из раздела «Подключение» в мои глобальные инструкции.

После этого можно просить словами: «пусти Telegram в наушники», «разложи окна на три колонки», «сделай экран потеплее».

Удалить

Выйди из Toolbox (шестерёнка → «Выйти из Toolbox»), удали /Applications/Toolbox.app, папку ~/Library/Application Support/Toolbox и файл ~/Library/LaunchAgents/local.toolbox.plist.

Инструкция для агента

AGENT.md — открыть как текст

Toolbox — инструкция для агента (Claude Code / Codex)

Ты работаешь на Mac, где установлен Toolbox — виджет в строке меню (значок — сетка 2×2) с системными инструментами на вкладках: Звук, Окна, Цвет. Человек пользуется им мышкой, а ты управляешь тем же самым из терминала командой toolbox. Прочитай файл целиком, потом выполни раздел «Подключение» в конце.

Где что лежит

ЧтоПуть

Команды работают, только когда приложение запущено (open -a Toolbox). Если toolbox audio list ничего не отвечает — запусти его.

Звук — каждое приложение на своё устройство

Для каждой программы: устройство вывода (колонки, наушники, аудиокарта, BlackHole…), громкость, mute и пара каналов многоканальной карты. Работает через Core Audio process tap (macOS 14.2+). Если Toolbox выйдет, программы сразу звучат как раньше.

toolbox audio list                                   # устройства, приложения, правила, активные маршруты
toolbox audio route "Музыка" "AirPods" --volume 0.8  # APP — имя или bundle id, DEVICE — имя/UID или "default"
toolbox audio route resolve "Scarlett" --channels 3-4
toolbox audio route Telegram default --mute
toolbox audio clear "Музыка"                         # или: clear all
  • Правило хранится по bundle ID и срабатывает, когда приложение начнёт звучать.
  • Отвалилось устройство (Bluetooth) — программа играет в системный выход, при подключении маршрут восстановится сам.
  • Нужно разрешение «Запись экрана и системного звука» → «Только системный звук». Без него маршруты не создаются, в audio-state.json будет ошибка — скажи человеку включить Toolbox там.

Окна — раскладка по шаблонам

Горячие клавиши ⌃⌥1…⌃⌥8: 2 рядом, 2 друг над другом, 2/3 + 1/3, 1 + 2, 3 колонки, 4 сеткой, 6 сеткой, на весь экран. Берутся последние активные окна экрана, повтор того же шаблона меняет окна местами по кругу.

toolbox windows layouts          # id шаблонов
toolbox windows apply grid4
toolbox windows list             # окна спереди назад → windows-state.json

Нужно разрешение «Универсальный доступ» (Accessibility).

Цвет — коррекция экранов

Баланс белого, яркость, контраст, гамма, уровень чёрного, по-канальная настройка, подсветка дисплеев Apple и цветовые профили.

toolbox color list
toolbox color set "LG" temp=5500 brightness=0.9
toolbox color reset all
toolbox color backlight "Встроенный" 0.6
toolbox color profile "LG" p3            # srgb | p3 | dci | 709 | 2020 | adobe | factory | ФАЙЛ.icc

Коррекция живёт, пока запущен Toolbox; при выходе macOS возвращает экраны к профилю.

Панель

toolbox show audio|windows|color   # открыть нужную вкладку
toolbox hide

Обновления

Если Toolbox ставили с хаба, в шестерёнке панели появляется «Доступно обновление X.Y» (и красная точка на значке). Клик ставит новую версию: Toolbox на секунду закроется и откроется снова, настройки сохранятся. То же из терминала: ~/.studio-hub/update.sh --install toolbox.

Правила

  • Не меняй маршруты звука и цвет экранов без просьбы человека: это сразу слышно и видно.
  • Перед audio route посмотри audio list, чтобы взять точные имена приложения и устройства.
  • Системные разрешения включает только человек (Системные настройки → Конфиденциальность и безопасность). Ты можешь открыть нужный раздел: open "x-apple.systempreferences:com.apple.preference.security?Privacy_Accessibility".

Подключение

  1. Проверь, что приложение стоит и отвечает: ~/Toolbox/toolbox audio list.
  2. Добавь в глобальные инструкции человека (~/.claude/CLAUDE.md для Claude Code, ~/.codex/AGENTS.md для Codex) блок: 
    ## Toolbox — системный виджет в строке меню
- Звук по приложениям, раскладка окон, цвет экранов. CLI: `~/Toolbox/toolbox audio|windows|color …`, справка `~/Toolbox/toolbox --help`.
- Подробности: `~/Toolbox/AGENT.md`. Маршруты звука и цвет меняю только по просьбе.
  3. Предложи включить автозапуск: ~/Toolbox/toolbox autostart on.
