Dial 0.4

Плавающий пульт: громкость, плеер, голосовой ввод

✳Установить через Claude❯_через CodexСкачать Dial-0.4.dmg1.5 МБ · 10 октября 2026

Круглый пульт поверх всех окон — тот же интерфейс, что у железного M5Stack Dial. Кольцо крутит громкость, клик ставит на паузу любой плеер, 🎙 включает диктовку агенту. На экране трек, статус агента, баланс и генерации ToAPIs. Фокус у окон не забирает.

Кольцо и плеер

Громкость колесом мыши, клик — play/pause, свайпы — треки. Работает с браузером, Яндекс Музыкой, Spotify.

Голос

🎙 шлёт клавишу F18 — привяжи к ней диктовку Claude или любого приложения.

Режимы

Плеер, Claude, Генерации (баланс ToAPIs), Resolve (кадр/секунда, Space), Часы.

Статус агента

Хуки Claude Code показывают на экране: работает, ждёт подтверждения, готово. Пропущенный ответ остаётся кнопкой с чатом — клик открывает его.

Домашний экран и игры

Двойной ⇧+клик — все режимы по кругу, выключение и три игры: Гонки, Прыгун (платформер), Пустошь (изометрическая RPG).

Установка

Запрос агенту (Claude Code / Codex)

Кнопки «Установить через Claude / Codex» вставляют его сами. Если приложение агента не открылось — скопируй и вставь вручную.
Или в Терминале
curl -fsSL https://mthought13.github.io/studio-hub/install.sh | bash -s -- dial
Ставит в «Программы», без предупреждения Gatekeeper. Обновление — та же команда.

Разрешения и требования

  • Универсальный доступ — чтобы пульт мог нажимать клавиши
  • python3 (Command Line Tools) — для трека и статусов на экране

Windows

Пока только Mac. На Windows громкость и плеер есть в быстрых настройках (Win + A).

Инструкция

Dial — плавающий пульт для Мака

Круглый пульт поверх всех окон:

  • Кольцо — громкость (колесо мыши или перетаскивание по кольцу).
  • Клик по экрану — play/pause в любом плеере (браузер, Яндекс Музыка, Spotify…). Свайп влево/вправо — предыдущий/следующий трек, вверх/вниз — смена режима.
  • 🎙 — голосовой ввод (шлёт клавишу F18, её привязывают к диктовке своего приложения).
  • Режимы: Плеер, Claude (голос + статус агента), Генерации (баланс ToAPIs), Resolve (кадр/секунда, Space), Часы.
  • Домашний экран — два ⇧+клика подряд (на железном Dial — двойное продавливание стекла): все режимы по кругу, кольцо выбирает, клик открывает. Там же Игры (Гонки, Прыгун, Пустошь) и выключение.
  • Пропущенный ответ агента — внизу экрана Claude остаётся кнопка с чатом, откуда пришёл пуш; клик по ней (или по самому уведомлению) открывает этот чат.

Фокус у окна не забирает: можно крутить громкость, не отрываясь от работы. Это тот же интерфейс, что будет у железного пульта M5Stack Dial.

Нужен macOS 13 или новее, Apple Silicon или Intel.

Установка

  1. Открой Dial.dmg и перетащи Dial в папку Applications, запусти.
  2. В первый раз macOS не откроет приложение без проверки Apple: Системные настройки → Конфиденциальность и безопасность → «Dial заблокировано» → «Всё равно открыть», или в Терминале: xattr -dr com.apple.quarantine /Applications/Dial.app
  3. Разреши «Универсальный доступ» (macOS спросит сама) — без него пульт не может нажимать клавиши.
  4. Чтобы на экране были трек и статусы, нужен python3. Если macOS предложит установить «инструменты разработчика» — согласись.

Полезное

  • Двигать: тянуть за тёмную рамку или за любое место с зажатым ⌘.
  • Меню (иконка в строке меню или правый клик): размер 100 / 50 / 25 %, кнопки рядом, скрыть, выйти.
  • Обновления приходят сами. Если в меню появилось «Доступно обновление», нажми — новая версия встанет сразу, Dial перезапустится.
  • Голос: в настройках своего приложения нажми на поле горячей клавиши диктовки и кликни 🎙 на пульте — запишется F18.

Подключить агента

Скажи Claude Code или Codex:

Прочитай инструкцию для агента из DMG Dial (или ~/Dial/AGENT.md) и подключи Dial: добавь блок в мои глобальные инструкции и спроси, нужны ли хуки статуса.

Удалить

Выйди из Dial (меню → «Выйти») и удали /Applications/Dial.app и папку ~/Dial.

Инструкция для агента

AGENT.md — открыть как текст

Dial — инструкция для агента (Claude Code / Codex)

Ты работаешь на Mac, где установлен Dial — плавающий круглый пульт поверх всех окон (как будущая железка M5Stack Dial). Кольцо крутит громкость, нажатие — play/pause, кнопка 🎙 — голосовой ввод. На круглом экране: трек, статус агента, баланс ToAPIs и генерации, часы. Прочитай файл целиком, потом выполни раздел «Подключение».

Как устроено

  • /Applications/Dial.app шлёт Маку настоящие клавиши: медиаклавиши (громкость, play/pause, треки — работает с любым плеером), F18 — голос, стрелки/Space в режиме Resolve. Фокус у окон не забирает.
  • Экран получает данные от моста — http://localhost:8765 (Python 3, без зависимостей). Приложение запускает его само: из ~/Dial/mac/dial_bridge.py, если папка есть, иначе из своей копии внутри Dial.app/Contents/Resources/Dial/.
  • Без моста (нет python3) пульт всё равно управляет Маком, экран показывает демо-данные. python3 приходит с Command Line Tools: xcode-select --install.
  • Состояние виджета: ~/Dial/.widget_state.json (trusted — выдан ли «Универсальный доступ», без него клавиши не уходят; version; update — новая версия с хаба, если ждёт установки; menu — пункты меню).
  • Обновления приходят с хаба сами. Если в меню Dial есть «Доступно обновление X», клик по нему ставит новую версию сразу (Dial перезапустится).

API моста

curl -s localhost:8765/state                     # громкость, трек, статус агента, баланс, генерации
curl -s -m 1 -X POST localhost:8765/hook -H 'Content-Type: application/json' --data-binary @-   # JSON хука Claude Code со stdin
curl -s -m 1 -X POST localhost:8765/claude -H 'Content-Type: application/json' -d '{"status":"working"}'   # вручную, для проверки
curl -s -m 1 -X POST localhost:8765/notify -H 'Content-Type: application/json' -d '{"kind":"gen_done","text":"Сцена 12 готова"}'
  • Статусы агента: idle, working, waiting (ждёт подтверждения), done. С хуками (ниже) мост знает статус каждого чата Claude: экран показывает статус открытого чата.
  • Пропущенный пуш: если Claude закончил или ждёт ответа в чате, на который человек не смотрит, внизу экрана Claude на Dial остаётся кнопка с названием этого чата; тап открывает чат. Тап по уведомлению «Claude закончил» — тоже.
  • Уведомления (kind): claude_done, claude_waiting, gen_done, gen_failed — оверлей на экране и звук.
  • Баланс и генерации берутся из ~/RefTray/.live.json, если установлен RefTray. Без него экран пишет «нет данных».

Голосовая кнопка (F18)

🎙 на виджете (и кнопка на железке) шлёт F18: нажал — down, отпустил — up. Чтобы она включала диктовку, человек привязывает F18 к голосовому вводу своего приложения: в Claude desktop — Настройки → поле горячей клавиши диктовки → кликнуть по 🎙 на виджете, пока поле в фокусе. У MacBook нет F13+, поэтому так проще всего.

Подключение

  1. Проверь, что мост отвечает: curl -s localhost:8765/state. Если нет — запусти open -a Dial.
  2. Статус агента и кнопка пропущенного пуша (по желанию, спроси человека). Для Claude Code добавь хуки в ~/.claude/settings.json (слей с существующими, не затирай). Команда пересылает мосту JSON хука как есть; Claude она не тормозит (1 с максимум, всегда код 0): 
    {
  "hooks": {
    "UserPromptSubmit": [{"hooks": [{"type": "command", "command": "curl -s -m 1 -X POST http://127.0.0.1:8765/hook -H 'Content-Type: application/json' --data-binary @- >/dev/null 2>&1; exit 0", "timeout": 5}]}],
    "Stop":             [{"hooks": [{"type": "command", "command": "curl -s -m 1 -X POST http://127.0.0.1:8765/hook -H 'Content-Type: application/json' --data-binary @- >/dev/null 2>&1; exit 0", "timeout": 5}]}],
    "Notification":     [{"hooks": [{"type": "command", "command": "curl -s -m 1 -X POST http://127.0.0.1:8765/hook -H 'Content-Type: application/json' --data-binary @- >/dev/null 2>&1; exit 0", "timeout": 5}]}]
  }
}

    Проверка: echo '{"hook_event_name":"Stop","session_id":"test"}' | curl -s -m 1 -X POST http://127.0.0.1:8765/hook -H 'Content-Type: application/json' --data-binary @- → {"ok": false} (мост отвечает, чужой id игнорирует). Старые хуки на POST /claude из прошлой версии этой инструкции замени этими. Для Codex — то же через его notify в ~/.codex/config.toml, если человек хочет.

  3. Добавь в глобальные инструкции человека (~/.claude/CLAUDE.md / ~/.codex/AGENTS.md): 
    ## Dial — плавающий пульт
- `/Applications/Dial.app`: громкость, плеер, F18 = голосовой ввод. Мост `http://localhost:8765` (GET /state, POST /hook — хуки Claude Code, POST /claude {status}, POST /notify {kind, text}). Пропущенный пуш Claude → кнопка с чатом внизу экрана Claude, тап открывает чат.
- Подробности: `~/Dial/AGENT.md`.
