# RefTray — инструкция для агента (Claude Code / Codex)

Ты работаешь на Mac, где установлен **RefTray** — плавающая панель поверх всех окон. Человек берёт из неё файлы мышкой (референсы для генераций, скриншоты, скачанное) и смотрит в ней состояние работы. **Ты управляешь панелью через файлы и два скрипта в `~/RefTray/`.** Прочитай этот файл целиком, потом выполни раздел «Подключение» в конце.

## Что видит человек
- **Вкладка «Рефы»** — набор референсов, который ты собрал под текущую генерацию: пронумерованные превью (видео играют прямо в панели), заголовок, заметка, текст промпта с кнопкой «Скопировать». Человек перетаскивает файлы в окно загрузки сервиса генерации.
- **Вкладка «Скрины»** — последние скриншоты macOS (⌘⇧3 / ⌘⇧4 / ⌘⇧5) и снимки кнопкой 📸, которая висит на окне браузера.
- **Вкладка «Входящие»** — новые файлы из папок слежки (по умолчанию `~/Downloads`) с кнопками проектов: один клик — файл переименован и перенесён в папку проекта.
- **Внизу:** «Задачи» (текущие задачи по проектам), «Генерации» (прогресс задач ToAPIs) и баланс ToAPIs (если есть ключ).

## Файлы в `~/RefTray/`
| Файл | Что это | Кто пишет |
|---|---|---|
| `tray.json` | текущий набор референсов | ты, через `reftray.py` |
| `history/` | все прошлые наборы | панель |
| `projects.json` | проекты и папки для «Входящих» | ты (по просьбе человека) |
| `todo.json` | текущие задачи | ты, через `todo.py`; человек — в панели |
| `tasks.jsonl` | задачи генерации, которые надо показать | ты, через `reftray.py task` |
| `.cmd` / `.state.json` | команды панели / её состояние | ты / панель |
| `inbox_log.jsonl` | журнал переносов из «Входящих» | панель |
| `catalog/*.md` | (по желанию) каталоги референсов по проектам | ты |

## 1. Отправить референсы в панель
```bash
python3 ~/RefTray/reftray.py set.json      # или: python3 ~/RefTray/reftray.py - <<'EOF' … EOF
```
```json
{
  "title": "Проект · сцена 12",
  "note": "Seedance 2 · 8 с",
  "prompt": "полный текст промпта (необязательно)",
  "items": [
    {"path": "/абсолютный/путь/depth.mp4", "role": "Depth map — движение", "tag": "@video1"},
    {"path": "~/refs/hero.png", "role": "Персонаж", "note": "только внешность"},
    "/просто/путь.png"
  ]
}
```
Правила:
- Порядок `items` = порядок референсов в промпте. Раскадровки и старые рендеры ставь последними.
- `tag` показывается вместо номера на превью (например `@image2`, как на платформе генерации).
- Промпт клади в `prompt`, но **всё равно давай его человеку текстом в чате**.
- Скрипт выходит с кодом 2 и перечисляет файлы, которых нет. Исправь пути, прежде чем говорить «готово».
- Чтобы быстро находить файлы, заведи каталог `~/RefTray/catalog/<проект>.md`: персонажи, локации, пропсы с полными путями и пометками, какая версия актуальная. Ищи в каталоге, а не сканируй диски каждый раз.

## 2. Текущие задачи (внизу панели)
```bash
python3 ~/RefTray/todo.py list [ПРОЕКТ]
python3 ~/RefTray/todo.py project ID "Название" --color "#E8742C"   # вкладка проекта
python3 ~/RefTray/todo.py add ID "Сцена 21 — рефы и промпт" --status next
python3 ~/RefTray/todo.py set ID ЗАДАЧА doing      # ЗАДАЧА = id или кусок текста
python3 ~/RefTray/todo.py done ID ЗАДАЧА
python3 ~/RefTray/todo.py edit ID ЗАДАЧА "новый текст"
python3 ~/RefTray/todo.py rm ID ЗАДАЧА
```
Статусы: `review` 👀 результат готов, человек должен проверить · `doing` ⏳ готовится или генерируется сейчас · `next` ○ дальше · `done` ✓ готово. Панель показывает только текущий этап: всё review и doing плюс два ближайших next.

**Веди список сам, без напоминаний:** отправил промпт или рефы → `doing`; генерация пошла или закончилась и ждёт глаз человека → `review`; человек утвердил, файл на месте → `done`; всегда держи 1–2 следующих конкретных шага как `next`. Формулировки короткие: «Сцена 21 — рефы и промпт». В начале работы над проектом смотри `todo.py list ПРОЕКТ`, чтобы понять, где остановились.

## 3. «Входящие»: проекты и папки (`projects.json`)
Панель создаёт файл при первом запуске (слежка за `~/Downloads`, проектов нет). Заполни его по проектам человека:
```json
{
  "watch": ["~/Downloads"],
  "projects": [
    {"id": "film", "name": "Фильм", "color": "#2563EB", "match": ["FILM", "фильм"],
     "dest": "~/Projects/Film/Входящие", "root": "~/Projects/Film"},
    {"id": "ep3", "name": "Сериал · EP3", "color": "#E8742C", "match": ["E03", "EP3"],
     "dest": "~/Projects/Series/EP3/1080", "ask": "chunk", "choicesFrom": "~/Projects/Series/EP3/chunks"},
    {"id": "ad", "name": "Реклама", "color": "#B3261E", "match": ["AD", "promo"],
     "dest": "~/Projects/Ad/Генерации", "ask": "slot", "choicesFrom": "~/Projects/Ad/Генерации"}
  ]
}
```
- `match` — слова в имени файла или в заголовке набора в «Рефах», по которым панель угадывает проект (★-кнопка).
- `ask: "chunk"` — спросит номер (подпапки `choicesFrom` с числовыми именами), файл станет `NN_1080.ext`. `ask: "slot"` — спросит слот (подпапки), файл станет `<слот>/<слот>_vN.ext`. Без `ask` — исходное имя, сразу в `dest`.
- Ничего не перезаписывается (добавляется `_v2`), у человека есть кнопка «Отменить». Тот же `id` используй для вкладок задач (`todo.py project`).

## 4. Прогресс генераций и баланс (только ToAPIs)
- Ключ ToAPIs лежит в `~/.config/toapis/api_key` (chmod 600). **Никогда не выводи его в чат и не пиши в файлы проектов.** Нет ключа — панель не показывает баланс и прогресс.
- Каждый номер задачи ToAPIs (`tsk_vid_…` видео, `tsk_img_…` картинки, `tsk_aud_…` музыка Suno) пиши в журнал **до** опроса статуса: файл `tasks*.jsonl` в папке проекта внутри папок слежки, одна JSON-строка `{"task_id": "...", "name": "понятное имя"}`. Панель находит такие журналы сама. Если журнал в другом месте: `python3 ~/RefTray/reftray.py task <id> "имя"`.
- После каждой платной генерации: `echo balance > ~/RefTray/.cmd` (баланс обновится и покажет списание) и назови человеку цену в долларах. Счёт аккаунта: `GET https://toapis.com/v1/user/balance` (`/v1/balance` — лимит ключа, это не баланс).

## 4б. Загрузки и траты
- Всё, что скачиваешь, показывай в панели: `python3 ~/RefTray/dl.py URL ПАПКА_ИЛИ_ФАЙЛ --label "имя"` (файлы не перезаписываются), или из Python: `from dl import Progress` (см. `~/RefTray/dl.py`).
- Траты ToAPIs по проектам считает `python3 ~/RefTray/spend.py` (панель запускает его сама раз в 3 минуты). Проект задачи определяется по папке, где лежит её журнал (`root` проекта в `projects.json`, иначе папка над `dest`), поэтому журналы задач держи внутри папки проекта. На вопрос «сколько ушло на проект» — запусти `spend.py` и перескажи отчёт.

## 5. Скриншоты
- Скриншоты macOS узнаются по метке `com.apple.metadata:kMDItemIsScreenCapture`, а не по имени файла. Папка — настройка macOS (`defaults read com.apple.screencapture location`), по умолчанию рабочий стол.
- Когда человек говорит «смотри скрин», открой самый новый файл-скриншот в этой папке. В имени может быть узкий неразрывный пробел перед AM/PM: скопируй файл во временную папку и читай копию.

## 6. Управление панелью
```bash
echo "show"     > ~/RefTray/.cmd   # показать   (hide · minimize · collapse · expand · tab 0|1|2 · balance · todo · play N · stop)
echo "state"    > ~/RefTray/.cmd   # через ~1 с появится ~/RefTray/.state.json
open -b local.reftray              # запустить панель, если она закрыта
```

## Чего не делать
- Не удаляй файлы человека без явной просьбы (у скриншотов в панели есть своя кнопка удаления с подтверждением).
- Не меняй `history/` и `inbox_log.jsonl` руками.
- Не вписывай ключи, пароли и токены ни в какие поля за человека.

## Подключение (сделай один раз)
1. Проверь, что панель стоит: `ls /Applications/RefTray.app ~/RefTray/reftray.py ~/RefTray/todo.py`.
2. Добавь в глобальные инструкции короткий блок (Claude Code: `~/.claude/CLAUDE.md`; Codex: `~/.codex/AGENTS.md`):
   ```markdown
   ## RefTray
   На этом Mac стоит RefTray — плавающая панель с референсами, скриншотами, входящими файлами и текущими задачами.
   Перед работой с референсами, генерациями или задачами прочитай ~/RefTray/AGENT.md и следуй ему:
   рефы — через `python3 ~/RefTray/reftray.py`, задачи — через `python3 ~/RefTray/todo.py` (веди их сам по ходу работы).
   ```
3. Спроси человека, какие у него проекты и где лежат их папки. Заполни `~/RefTray/projects.json` и заведи вкладки задач (`todo.py project …`) с первыми 2–3 задачами по каждому проекту.
4. Если человек хочет быстрый поиск референсов — составь `~/RefTray/catalog/<проект>.md`.
5. Отправь в панель тестовый набор из 1–2 файлов и попроси человека проверить, что он видит превью и может перетащить файл в браузер.
