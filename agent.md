# Studio Hub — каталог для агента

Ты — Claude Code или Codex на Маке человека из команды. Здесь внутренние приложения студии для macOS:
панели, виджеты и утилиты, которыми можно управлять из терминала. Каждое ставится одной командой.

Читай этот каталог и инструкции приложений через `curl -s` (сайт в локальной сети, по http).

## Как ставить
```bash
curl -fsSL https://mthought13.github.io/studio-hub/install.sh | bash -s -- <id> [<id> …]
```
- Ставь только то, что попросил человек. Если не сказал что — покажи список ниже и спроси.
- Команда скачивает пакет, кладёт приложение в «Программы» (или `~/Applications`), снимает карантин Gatekeeper
  и запускает его. Повторный запуск = обновление.
- После установки **прочитай инструкцию приложения** (`AGENT.md`, ссылка ниже; копия — в домашней папке приложения)
  и выполни её раздел «Подключение»: обычно это блок в `~/.claude/CLAUDE.md` или `~/.codex/AGENTS.md`.
- Вместе с первым приложением включается **автообновление** (LaunchAgent `local.studiohub.update`):
  каждые 10 минут сверяет версии с хабом; нашлась новая — окно «Обновить / Позже» с тем, что нового.
  Проверить сейчас: `~/.studio-hub/update.sh --now`, выключить: `~/.studio-hub/update.sh off`.
- Системные разрешения macOS (Универсальный доступ, Запись экрана) включает сам человек — скажи, какие нужны.
- Пароли, ключи и входы в аккаунты человек вводит сам, не проси прислать их в чат.

## Приложения

### RefTray (`reftray`) — Плавающая панель референсов для генераций
- Окно поверх всех окон. Агент собирает в него референсы под генерацию, а ты перетаскиваешь их мышкой прямо в окно загрузки Seedance, Nano Banana или любого другого сервиса. Там же свежие скриншоты, новые загрузки с раскладкой по проектам, текущие задачи, прогресс генераций и баланс ToAPIs.
- Версия: 1.1 от 2026-10-02. Платформа: macOS 14+ · Apple Silicon и Intel.
- Установка: `curl -fsSL https://mthought13.github.io/studio-hub/install.sh | bash -s -- reftray`
- Инструкция для агента: https://mthought13.github.io/studio-hub/apps/reftray/AGENT.md (после установки: `~/RefTray/AGENT.md`)
- Разрешения: Доступ к Рабочему столу и Загрузкам — для скриншотов и входящих; Запись экрана — только для кнопки 📸.

### Toolbox (`toolbox`) — Звук по приложениям, раскладка окон, цвет экранов
- Значок-сетка в строке меню с системными инструментами на вкладках. Каждой программе — своё устройство вывода и громкость, окна раскладываются по шаблонам одной клавишей, экраны подстраиваются по цвету. Всё это можно попросить у агента словами.
- Версия: 1.3 от 2026-10-04. Платформа: macOS 14.2+ · Apple Silicon и Intel.
- Установка: `curl -fsSL https://mthought13.github.io/studio-hub/install.sh | bash -s -- toolbox`
- Инструкция для агента: https://mthought13.github.io/studio-hub/apps/toolbox/AGENT.md (после установки: `~/Toolbox/AGENT.md`)
- Разрешения: Запись системного звука («Только системный звук») — для вкладки «Звук»; Универсальный доступ — для вкладки «Окна».

### Dial (`dial`) — Плавающий пульт: громкость, плеер, голосовой ввод
- Круглый пульт поверх всех окон — тот же интерфейс, что у железного M5Stack Dial. Кольцо крутит громкость, клик ставит на паузу любой плеер, 🎙 включает диктовку агенту. На экране трек, статус агента, баланс и генерации ToAPIs. Фокус у окон не забирает.
- Версия: 0.3 от 2026-10-02. Платформа: macOS 13+ · Apple Silicon и Intel.
- Установка: `curl -fsSL https://mthought13.github.io/studio-hub/install.sh | bash -s -- dial`
- Инструкция для агента: https://mthought13.github.io/studio-hub/apps/dial/AGENT.md (после установки: `~/Dial/AGENT.md`)
- Разрешения: Универсальный доступ — чтобы пульт мог нажимать клавиши; python3 (Command Line Tools) — для трека и статусов на экране.

### TgFetch (`tgfetch`) — Файлы из Telegram по просьбе словами
- Консольная утилита для Claude Code и Codex: находит чат, топик и человека и скачивает присланные файлы в папку проекта. Работает от твоего аккаунта и только читает. Отправка — отдельной командой и только после твоего «да».
- Версия: 1.0 от 2026-10-02. Платформа: macOS · нужен python3.
- Установка: `curl -fsSL https://mthought13.github.io/studio-hub/install.sh | bash -s -- tgfetch`
- Инструкция для агента: https://mthought13.github.io/studio-hub/apps/tgfetch/AGENT.md (после установки: `~/TgFetch/AGENT.md`)
- Разрешения: python3 (Command Line Tools); Свои api_id и api_hash с my.telegram.org — вход делаешь сам.
